Dataverse Skills · Tu agente de código ahora habla Dataverse

Microsoft acaba de publicar un plugin oficial — open source, MIT — que enseña a Claude Code y a GitHub Copilot a construir, consultar y administrar entornos de Dataverse usando lenguaje natural. Una sola instalación; el resto lo orquesta el agente.

⏱ Lectura: 8 min · Demo en clase: 12 min · Fuente: devblogs.microsoft.com (oct 2025)
01

Qué es Dataverse Skills

2 min

🎯 La frase de Microsoft

"Build, query, and manage Microsoft Dataverse through natural language."

Es un plugin oficial de Microsoft, open source bajo licencia MIT, que se instala en tu coding agent (Claude Code o GitHub Copilot) y le enseña a operar Dataverse. El usuario nunca invoca una skill directamente — describes la intención en español o inglés, y el agente decide qué skill cargar.

🧩 Cómo encaja con lo que ya sabéis

En la S2 vimos qué son las skills y los agents en Claude Code. Esto es exactamente eso: un paquete de skills publicado por Microsoft, que se instala vía el sistema oficial de plugins.

  • Se instala con /plugin install — sin clonar repos
  • Trae 8 skills especializadas (conectar, consultar, modelar, administrar…)
  • Levanta automáticamente un MCP server contra tu entorno Dataverse
  • Funciona con PAC CLI, Python SDK y Web API por debajo

💼 Por qué nos importa en LitoClean

Trabajamos con Dataverse a diario — soluciones, tablas, columnas, plugins, formularios, datos. Hoy todo eso pasa por maker.powerapps.com con clics y formularios.

  • Crear una tabla con 8 columnas: ~5 minutos de clics
  • Importar un CSV: pasar por el wizard, mapear, esperar
  • Empaquetar una solución: pac solution pack + flags

Con Dataverse Skills: una frase. El agente hace el trabajo.

02

Antes vs. Después

2 min

❌ Antes (flujo manual)

  • Abrir make.powerapps.com
  • Seleccionar entorno correcto del dropdown
  • Solutions → New solution → rellenar formulario
  • Por cada tabla: New table → nombre → tipo → ownership…
  • Por cada columna: data type, required, searchable…
  • Crear relación lookup con otra tabla
  • Volver a la solution, añadir tabla manualmente
  • Importar CSV con el wizard de "Get data"
  • Total: 30-60 minutos por solución pequeña

✅ Después (con Dataverse Skills)

Un solo prompt en Claude Code:

"Crea una solución de Reclutamiento con tablas para Posiciones, Candidatos, Entrevistadores, Entrevistas y Feedback. Carga datos de ejemplo desde candidatos.csv y muéstrame las posiciones abiertas con más de 3 candidatos."
  • El agente descubre el entorno y configura MCP
  • Crea solución vía PAC CLI
  • Construye tablas, columnas, relaciones
  • Genera y ejecuta Python para cargar el CSV
  • Lanza la query y te devuelve la respuesta
03

Las 8 skills incluidas

3 min

El agente las carga bajo demanda — no necesitas memorizarlas, pero conocerlas ayuda a entender qué puedes pedir.

dv-connect

Setup inicial: instala CLI/SDK, autentica vía PAC CLI o Azure CLI, y registra el MCP server.

dv-query

Lee, filtra, pagina y agrega registros. Carga resultados en pandas DataFrames para analítica.

dv-data

CRUD, importaciones masivas, carga desde CSV, upserts con claves alternas.

dv-metadata

Diseña y modifica el modelo: tablas, columnas, relaciones, formularios y vistas.

dv-solution

Ciclo de vida de soluciones: crear, exportar, importar, mover entre entornos.

dv-admin

Administración del entorno: bulk delete, retención, auditoría, settings.

dv-security

Asignación de roles, accesos, business units, elevación de admin.

dv-overview

Routing transversal — el agente la usa para decidir qué otra skill cargar.

📌 Las 3 fases que cubre el plugin: Connect (descubrir entorno y autenticar) → Build (crear solución, tablas, columnas, formularios, vistas) → Operate (cargar datos, consultar, perfilar calidad). Todo orquestado desde lenguaje natural.

04

Instalación — un solo comando

3 min

📦 Para Claude Code

/plugin install dataverse@claude-plugins-official

Lo escribes dentro de Claude Code (en el prompt). Se instala como plugin oficial — igual que cualquier otro plugin del marketplace.

📦 Para GitHub Copilot

/plugin install dataverse@awesome-copilot

Funcionalidad idéntica — ambos agentes leen el mismo Markdown de definición de skills.

▶

Primera prueba después de instalar

No hay que configurar nada manualmente. Lanza este prompt y la skill dv-connect se encarga de todo:

"Connect to Dataverse"

El agente:

  1. Verifica que tienes PAC CLI y Python instalados (los instala si faltan)
  2. Lanza pac auth create contra tu tenant — abre browser para login
  3. Detecta tus entornos disponibles y te pregunta cuál usar
  4. Registra un MCP server llamado dataverse-<orgname>
  5. Verifica con pac auth list que la conexión activa es correcta

✅ Cómo saber que funcionó: al final ves un MCP server dataverse-{nombre-de-tu-org} registrado en Claude Code, y pac auth list muestra el entorno activo.

⚠️ Prerrequisito único: tener acceso a un entorno Dataverse — vía Power Apps, Dynamics 365, plan de Power Platform, o el Power Apps Developer Plan gratuito. Si todavía no tienes uno, regístrate en powerapps.microsoft.com/developerplan.

05

Catálogo de prompts que funcionan

3 min

Estos son los ejemplos que Microsoft incluye en su anuncio. Patrón claro: describe el resultado, no el método.

🔍 Consultas analíticas

"Show me my open deals over $100K closing this quarter"
"List all contacts in Madrid with no activity in the last 90 days"

El agente traduce a OData/FetchXML, ejecuta y devuelve la respuesta tabulada.

📥 Importación de datos

"Import this CSV into the contacts table"
"Bulk-load candidates.csv into pfx_candidate using email as alternate key"

Carga vía Python SDK con upserts — sin abrir el wizard del portal.

🏗️ Modelado

"Create a customer feedback table with name, rating, and comment columns"
"Add a lookup from pfx_invoice to pfx_customer named Cliente"

Crea metadata y la añade a la solución activa automáticamente.

📦 Ciclo de vida

"Pull the schema and pack it into a solution"
"Export the smart_project_solution as managed and deploy to UAT"

PAC CLI orquestado — sin recordar flags ni rutas.

🧹 Administración

"Bulk delete activities older than 2024"

Usa la API de bulk delete con job programado, no eliminación uno a uno.

🔐 Seguridad

"Add a teammate to the sales team on the dev environment"

Asigna roles vía la skill dv-security, controlando el entorno destino.

06

Cómo lo aplicaríamos al caso de hoy

3 min

Hoy estamos analizando la Canvas App "Registro Semanal de Horas" (pfx_weeklytimeentrypage_40d1a) sobre la solución smart_project_solution. Esa solución vive en Dataverse, con tablas como pfx_time_entry, pfx_time_entry_day, pfx_project… Veamos qué podríamos pedirle a Claude Code con Dataverse Skills instalado:

📊 Auditoría rápida del modelo

"Lista las tablas de smart_project_solution con su recuento de columnas y de registros"

En lugar de abrir el portal y clicar tabla por tabla, una respuesta tabulada en segundos.

🔎 Detectar datos huérfanos

"¿Cuántos pfx_time_entry_day apuntan a cabeceras pfx_time_entry inexistentes?"

Cruzar tablas para encontrar inconsistencias — útil antes de desplegar a otro entorno.

🧪 Generar datos de prueba

"Crea 50 cabeceras pfx_time_entry de las últimas 4 semanas para 5 usuarios random, en estado Borrador"

Ideal para repoblar entornos de desarrollo sin scripts manuales.

📋 Snapshot de OptionSets

"Exporta los valores de pfx_time_entry_status_choice y pfx_role_choice a un Markdown"

Documenta los Choice (Borrador/Enviado/Aprobado/Rechazado…) sin abrir el solution explorer.

💡 El gancho: el documento analisis-time-tracker.md que estamos viendo hoy lo construyó Claude leyendo el YAML del .msapp. Con Dataverse Skills, podría ir más allá y consultar el Dataverse en vivo — combinar análisis estático del front (Canvas) con análisis dinámico del back (datos reales).

08

Lo que aún NO hace (y consideraciones)

2 min

🚫 Fuera de scope (por ahora)

  • Plugins .NET de Dataverse — el plugin no genera ni registra ensamblados
  • JavaScript de formularios — para eso seguimos con la skill propia dataverse-form-javascript de este repo
  • Power Automate flows — no crea ni edita flujos
  • Canvas Apps / Model-Driven UI — gestiona Dataverse, no la capa de aplicación

⚠️ Buenas prácticas

  • Empieza en un entorno Dev — bulk delete y cambios de schema son delicados
  • Revisa siempre el plan que el agente propone antes de aceptar
  • El plugin respeta los permisos de tu cuenta — no eleva privilegios
  • Los pac auth tokens viven en tu máquina; trátalos como credenciales

🔒 Repo público — recordatorio: al usar Dataverse Skills, el agente puede llegar a leer datos reales del entorno. Nunca peguéis nombres de proyectos reales, IDs de cliente o resultados de queries con datos sensibles en commits, prompts del repo público o capturas de pantalla compartidas.
